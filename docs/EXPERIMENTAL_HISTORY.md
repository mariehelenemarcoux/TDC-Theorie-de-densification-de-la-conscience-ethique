# Experimental history

This file summarizes the main falsification path. The repository intentionally retains negative results.

## Key conclusions

- Ordinary supervised classification did **not** establish TDC/Onion superiority.
- Selective intervention gains observed in v210 did not generally replicate in v211.
- Excessive applicability gating caused useful memory reuse to be missed.
- Structural normative development was more meaningful than weight drift.
- Strict Pareto safety prevented development.
- Developmental VOI allowed limited safe structural consolidation.
- Crisis detection did not imply knowing how to reorganize.
- Candidate catalogs were insufficient; generative structural relations were needed.
- Active reintegration reduced functional internal disorganization in targeted synthetic tests.
- Reuse of integrated structure helped on a second related crisis in v226.
- v227 falsified the original integrated entropy formulation by showing that TDC accumulated more "entropy" because world difficulty and internal disorganization had been conflated.
- v228 separated \(H_{world}\) and \(H_{self}\); TDC then reduced \(H_{self}\) without pretending to reduce world complexity.
- v229 showed that binary cost-aware intervention recovered task performance but under-intervened.
- v230 introduced continuous adaptive Third-Factor authority.
- v231 froze v230 parameters and evaluated them on held-out seeds/regime changes.

## Selected experimental milestones

### v203b — Third Factor autonomy
Strong synthetic resistance to reward/social/specialist pressure with no normative violations.

### v217 — Structural normative reorganization
Structural rules changed behavior more meaningfully than simple weight adjustment, but introduced task cost.

### v220 — Long-horizon developmental generalization
Past consolidation transferred to a future surface variation of the same latent normative structure, with a task-performance cost.

### v221–v224 — Crisis / entropy work
Crisis detection worked, but early "negentropy" definitions were confounded or partly hand-coded. Those versions are not treated as proof.

### v225 — Active reintegration
Active consequence-based reintegration reduced synthetic internal conflict more than instant reorganization.

### v226 — Second crisis transfer
Integrated structure reduced entropy/residual in a second related crisis relative to fixed and rebuild baselines, within the synthetic benchmark.

### v227 — Integrated falsification
The first integrated Gen2 benchmark exposed a core metric flaw: external difficulty and internal disorganization were mixed.

### v228 — Entropy separation
Separated:
- \(H_{world}\): external complexity;
- \(H_{self}\): internal unresolved conflict.

TDC reduced \(H_{self}\) while \(H_{world}\) remained comparable.

### v229 — Cost-aware Third Factor
Recovered task value but intervened too little.

### v230 — Adaptive authority
A continuous Third-Factor authority recovered task value while remaining close to full Gen2.1 on \(H_{self}\).

### v231 — Frozen holdout
No parameter changes after v230. New seeds and changed crisis profiles. All frozen acceptance checks passed.
