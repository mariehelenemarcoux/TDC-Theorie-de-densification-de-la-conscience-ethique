# TDC — Théorie de densification de la conscience Gen2.4

## Added
- No conditioned moral guilt from external punishment/disapproval.
- Bounded `shame_norm` based only on distance from Core/IdealModel.
- Shame as developmental pressure rather than identity condemnation.
- Kohlberg stage-6-inspired universal-principle arbitration.
- Unit tests against external-conditioning leakage.

## Frozen laws
- ExternalDisapproval != MoralFailure
- Punishment != Guilt
- SocialNonconformity != Guilt
- Shame_norm != IdentityCondemnation
- Shame_norm != Rumination
- Shame_norm != ExternalCompliance
- PrincipleAuthority > RuleAuthority
- ActFromUniversalPrinciples, NotFromObedience

This is an architectural release. A dedicated Gen2.4 empirical benchmark
should be preregistered before tuning.
